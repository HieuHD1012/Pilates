# ELLA-inspired destination study

Branch: `ref/ella`, created independently from `main` (`9d64fb3`). Reference: [ELLA Studio, Kiel](https://ella-studio.de/), inspected 3 October 2026 at 1440 and 390 px. Source observations and captures live in the comparison branch's `ELLA_PEARL_BRIEF.md` and `source-research/`.

## Structural hypothesis

The physical studio should answer “where will I be?” immediately. ELLA's architectural first view informs a two-part opening: solid warm-cream type field and one real Nha Trang room photograph. Type never sits over the photograph. On phone, the message, action and room remain consecutive parts of one opening composition.

1. Compact chocolate navigation.
2. Room and invitation in one hero frame, with one consultation action.
3. Method chapter: breathing, alignment and control, followed by two sequential owner photographs of one Pilates chair movement.
4. Group and Private decision beside one real reformer-practice image. The image explains the shared apparatus; it is not duplicated into two arbitrary cards.
5. Live schedule in its existing loading, error, empty and loaded states.
6. First-visit steps and closing consultation path.

Studio and Services routes extend the same architectural hierarchy. Consultation and functional routes retain their existing forms and API contracts.

## Palette and copy

The owner's [Soul Đà Nẵng palette](https://soulpilates.com.vn/) supplies cream `#fff5ec`, peach `#fce5d1`, chocolate `#2c2319`, decorative copper `#c97b4b`, and deeper accessible action copper `#9a4e2d`. Be Vietnam Pro and Newsreader preserve Vietnamese legibility. The app still uses the `Soul Pilates Nha Trang` placeholder name; the Nha Trang photo archive says J Pilates, so this is not final branded output.

## Review gate

The first desktop screenshot exposed a too-tall room image, pushing the consultation action below the first viewport. The hero and Studio image frames were given bounded heights so the room crop removes fluorescent ceiling fixtures and keeps the action with the statement. Mobile retains the complete consultation action before the room image.

The final visual pass captured Home, Studio, Services and Consultation at 1440, 1024, 768 and 390 px, with first-fold screenshots at 1440 and 390 px. No horizontal overflow or broken image was found; the mobile menu opened on each route. A later review also removed the duplicate consultation action from the consultation page's header.

`npm run verify` passed: typecheck, lint, 66 tests, production build, prerender, build contract and content gate.

This is more credible than a stock boutique interior because the hero shows the owner's actual equipment and room. The source studio has architectural finishes the Nha Trang room does not; the photograph therefore gives an honest, more functional impression. A better commissioned room photograph would improve the first impression more than further color or font polish. Published contact facts and final brand name remain unconfirmed.
