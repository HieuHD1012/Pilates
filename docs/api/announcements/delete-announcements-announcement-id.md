## 1. Overview

- **Purpose:** Xoá hẳn một thông báo.
- **Method:** `DELETE`
- **Endpoint:** `/announcements/{announcement_id}`
- **Auth:** `Authorization: Bearer <access_token>` — vai **ADMIN, STAFF**
